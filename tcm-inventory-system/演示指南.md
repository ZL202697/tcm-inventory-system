```python
# 处方发药（自动扣库存）
@app.route("/api/prescriptions/<int:rx_id>/dispense", methods=["PUT"])
def dispense_prescription(rx_id):
    user, err = require_login()
    if err: return err
    row = query("SELECT * FROM prescriptions WHERE id = %s", (rx_id,), one=True)
    if row["status"] != "approved":
        return fail("只有已审核的处方才能发药")
    # 扣减库存
    items = query("SELECT * FROM prescription_items WHERE prescription_id = %s", (rx_id,))
    for item in items:
        herb = query("SELECT * FROM herbs WHERE code = %s", (item["herb_code"],), one=True)
        if herb:
            deduct = int(float(item["dosage"].replace("g","")) * item["quantity"])
            execute("UPDATE herbs SET quantity=%s WHERE code=%s", (max(0, herb["quantity"]-deduct), item["herb_code"]))
    # 更新处方状态
    execute("UPDATE prescriptions SET status='dispensed', dispenser=%s, dispense_time=%s WHERE id=%s",
            (user["username"], time.strftime("%Y/%m/%d %H:%M:%S"), rx_id))
    return ok(None, "处方发药成功，库存已扣减")
```

#### 2.3 db.py（数据库层）
**文件位置：** `backend/db.py`（约120行）

**核心设计：智能双模式**
- 自动检测：默认SQLite，设置 `USE_MYSQL=1` 则用MySQL
- 占位符自动转换：MySQL用 `%s`，SQLite用 `?`，自动适配
- 统一接口：`query()` / `execute()`，上层代码无需关心底层数据库
- SQLite字典游标：包装原生游标，返回字典格式（与MySQL DictCursor一致）

**关键代码片段：**
```python
def _convert_placeholders(sql):
    """将 SQL 中的 %s 占位符转换为 SQLite 的 ?"""
    if is_mysql():
        return sql
    return sql.replace("%s", "?")

def query(sql, args=None, one=False):
    conn = get_conn()
    try:
        if is_mysql():
            with conn.cursor() as cur:
                cur.execute(sql, args)
                return cur.fetchone() if one else cur.fetchall()
        else:
            cur = DictCursorSqlite(conn.cursor())
            cur.execute(sql, args)
            rows = cur.fetchall()
            return rows[0] if one and rows else rows
    finally:
        conn.close()
```

### 第3部分：前后端交互演示

**统一API规范：**
- 请求头：`X-User: <用户名>`（登录态传递）

**典型交互流程（新建处方）：**

2. 后端验证权限（医生/管理员）→ 生成处方编号 → 计算总金额
3. 写入 prescriptions 表 + prescription_items 表

5. 前端刷新列表，展示新处方（状态：待审核）

**发药流程（库存联动）：**
1. 前端点击发药 → `PUT /api/prescriptions/<id>/dispense`
2. 后端验证处方状态（必须是已审核）
3. 遍历处方明细，逐味扣减药材库存
4. 更新处方状态为已发药，记录发药人和时间
5. 返回成功，前端刷新
6. 可在药材管理页面验证库存已扣减

## 五、常见问题

### Q: 启动报错 "未检测到 Python"
A: 请先安装 Python 3.8+，安装时勾选 "Add Python to PATH"，安装后重启命令行。

### Q: 端口5000被占用怎么办？
A: 修改 `backend/app.py` 最后一行的端口号，或设置环境变量 `PORT=8080`。

### Q: 如何切换到 MySQL？
A: 设置环境变量 `USE_MYSQL=1`，并配置 `DB_HOST/DB_PORT/DB_USER/DB_PASSWORD/DB_NAME`，然后重新运行 `init_db.py`。

### Q: 如何重置所有数据？
A: 删除 `backend/herb_management.db` 文件，重新运行 `init_db.py` 即可。

### Q: 浏览器打开页面但数据加载失败？
A: 确保通过 `http://127.0.0.1:5000` 访问，不要直接双击HTML文件（会导致跨域失败）。
